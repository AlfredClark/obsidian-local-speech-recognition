# Local Speech Recognition

[English](../README.md) | **简体中文**

在 Obsidian 中使用本地部署的 sherpa-onnx 服务做离线语音识别。按下快捷键说话，识别文本直接插入到光标处。无云端，无需 API Key。

## 功能

- 通过本地 WebSocket（默认 `ws://127.0.0.1:6006`）调用 `sherpa-onnx-offline-websocket-server` 做离线识别。
- 快捷键触发录音，支持单次点击切换与按住说话两种模式。插件不预设快捷键，请在设置 → 快捷键中自行指定。
- 麦克风选择：枚举音频输入设备，一键刷新。
- 16 kHz 16-bit 单声道管线：`AudioWorklet` 采集 + 线性降采样。
- 智能投递：Markdown 编辑器聚焦（源码模式）时插入到光标处，否则写入剪贴板并 Notice 提示。
- 词库（针对中文设计）：经编辑器右键菜单添加词语；识别后命中的词语会加下划线，点击可替换为同音词。可选的模糊音匹配容忍平翘舌与前后鼻音差异。
- 侧边栏视图（Ribbon 图标）：「词库管理」页管理词条，「服务管理」页控制服务。
- 服务管理：手动启动/停止/重启、随插件自动启动、连接测试。
- 三语界面：English / 简体中文 / 繁體中文，跟随 Obsidian 界面语言，也可手动指定。

## 运行要求

- Obsidian 1.13.1 及以上（使用了声明式设置 API）。
- 仅桌面端。插件需要拉起本地子进程并采集麦克风音频，移动端均不可用。
- 需要 `sherpa-onnx-offline-websocket-server` 可执行文件与模型文件夹。当前仅支持 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` 模型的 int8 版本：文件夹内须包含 `model.int8.onnx` 与 `tokens.txt`，其他模型需要等待后续版本适配。

## 下载地址

- sherpa-onnx 发布页（服务端可执行文件）：<https://github.com/k2-fsa/sherpa-onnx/releases>
- 预训练 ASR 模型：<https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models>

## 安装

1. 在 Obsidian 设置 → 第三方插件 → 浏览中搜索“Local Speech Recognition”安装，安装后启用插件。
2. 如需手动安装，从 GitHub Release 下载 `main.js`、`manifest.json`、`styles.css`，复制到 `<vault>/.obsidian/plugins/local-speech-recognition/`，重载 Obsidian 后在设置 → 第三方插件中启用。

## 快速开始

1. 从上方链接下载服务端可执行文件与模型，解压模型文件夹到本地。
2. 打开插件设置 → 服务设置：填写服务端可执行文件路径与模型文件夹路径，确认主机/端口/线程数，点连接测试或启动服务（也可开启自动启动）。
3. 打开语音输入：选择麦克风。列表为空或无名称时，先允许一次麦克风权限，再点刷新麦克风。然后选择触发模式。
4. 打开 Obsidian 设置 → 快捷键，找到“切换语音识别”，指定一个快捷键。
5. 聚焦一篇笔记的编辑区，按快捷键开始说话，再按一次停止。文本插入到光标处。若当时没有聚焦编辑器，结果会写入剪贴板并 Notice 提示。
6. 可选：为专有名词或术语建立词库。在编辑器中选中词语，右键选择「添加到词库」；之后的识别会为其加下划线并提供一键替换。详见下文[词库](#词库)。

## 设置说明

通用设置：

| 设置     | 说明                                            |
| -------- | ----------------------------------------------- |
| 插件语言 | 界面语言：跟随系统、English、简体中文、繁體中文 |
| 折叠分组 | 开启后设置分组渲染为可导航子页                  |

服务设置：

| 设置                 | 说明                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 服务端可执行文件路径 | `sherpa-onnx-offline-websocket-server` 可执行文件路径                                                            |
| 模型文件夹路径       | `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` 的 `model.int8.onnx` + `tokens.txt`（暂仅支持该 int8 版本） |
| 监听主机 / 服务端口  | 服务监听地址（默认 `127.0.0.1` / `6006`）                                                                        |
| CPU 线程数           | 服务神经网络使用的线程数                                                                                         |
| 连接测试             | 拨号已配置的 WebSocket 地址检查可达性                                                                            |
| 自动启动服务         | 插件加载时自动拉起服务                                                                                           |
| 启动/关闭/重启       | 手动生命周期控制，按服务状态显隐                                                                                 |

语音输入：

| 设置       | 说明                             |
| ---------- | -------------------------------- |
| 麦克风     | 输入设备；留空表示系统默认       |
| 刷新麦克风 | 重新枚举音频输入设备             |
| 触发模式   | 单次点击切换，或按住说话（见下） |

词库设置：

| 设置                   | 说明                                                                            |
| ---------------------- | ------------------------------------------------------------------------------- |
| 启用词库               | 开关全部词库功能，含侧边栏词库页与编辑器集成（默认开启）                        |
| 模糊音匹配             | 令仅平翘舌或前后鼻音有差异的词语也视为同音（默认关闭，见下文「词库」）          |
| 导出 / 导入 / 清空词库 | 备份为 JSON、从 JSON 或每行一词的纯文本导入、永久删除全部词条（关闭词库时隐藏） |

## 使用说明

- 单次点击切换：按一次开始，再按一次停止并识别。
- 按住说话（过渡语义）：按一次开始；松开快捷键或再按一次停止并识别。因 Obsidian 快捷键只给按键按下事件，精确的按住语义暂为近似实现。
- 单次录音上限 280 秒（服务端超过 300 秒拒连），到时自动停止并识别。
- 识别进行中再次触发会被 Notice 拒绝，避免并发连接覆盖结果。
- 词库：在编辑器中选中文本，右键选择「添加到词库」。此后每次识别都会扫描词库词语，命中的片段会加下划线，点击即可在弹出的同音候选词中替换。
- 在侧边栏（Ribbon 图标）→「词库管理」页管理词条：搜索、按启用状态筛选、新增/编辑/删除，以及批量启用/禁用/删除。

## 词库

词库**针对中文设计**。每个词条由「词语 + 拼音」组成，匹配时用拼音比对识别文本，因此即便语音模型返回的是同音字也能命中——例如词库收录了「知识」，那么识别出的「资石」（拼音同为 `zhi shi`）会被加上下划线，一键即可改正。由于匹配基于拼音，词库对非中文文本不起作用：拉丁字符片段会被忽略，没有拼音的词语也会跳过。

开启「模糊音匹配」后，仅平翘舌（zh/z、ch/c、sh/s）或前后鼻音（an/ang、en/eng、in/ing、ian/iang、uan/uang）有差异的词语也会被视为同音。这对口音与模型混淆有帮助，但会以精确度换取召回——开启后「张」与「脏」会互相可替换——因此默认关闭。

说明：

- 添加词语时自动生成拼音；可在编辑弹窗中手动修改，或按词语重新生成。
- 词条可以「禁用」而非删除；禁用后仍保留在列表中，但不参与匹配。
- 「权重」用于给同拼音的词条排序，权重越高在替换候选中越靠前。
- 重复添加完全相同的「词语 + 拼音」会经 Notice 提示且不写入；同音不同字可并存。

## 常见问题

| 现象                   | 处理办法                                                     |
| ---------------------- | ------------------------------------------------------------ |
| 麦克风列表为空或无名称 | 先允许一次麦克风权限，再点刷新麦克风                         |
| 提示服务未运行         | 在设置中启动服务，或开启自动启动                             |
| 连接测试失败           | 检查可执行文件/模型路径、主机端口，以及端口是否被占用        |
| 麦克风被拒绝 / 未找到  | 检查系统麦克风权限，确认所选设备已连接                       |
| 识别失败               | 查看 Notice 详情；若是退出码，检查模型文件夹结构是否符合预期 |
| 意外词语被加下划线     | 模糊音匹配处于开启状态；可在词库设置中关闭                   |

## 隐私

识别全程在本地进行。麦克风音频只发送到你配置的 WebSocket 地址（默认本机），不会发给任何第三方。
